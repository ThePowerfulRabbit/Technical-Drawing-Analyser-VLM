Identify the following regions in the given engineering drawing:       
 - flat_pattern: an unfolded sheet-metal representation, if present.
 - orthographic_view: front, top, or side projection views.
 - isometric_view: a 3D pictorial/isometric view.
 - section_view: a sectional view showing an internal cut.
 - title_block: the drawing information block.
 
 For each region that is present, return a bounding box that contains
 the complete region.
 
 For orthographic_view, identify every individual projection view
 separately and return a separate bounding box for each individual view.
 
IMPORTANT BOUNDING BOX RULES:

1. The bounding box must contain the COMPLETE visual view.
2. Do NOT tightly hug the visible drawing geometry.
3. Leave a clear 20% margin of empty space between the drawing geometry and every
   side of the bounding box.
4. The margin must be large enough that no part of the drawing can be
   accidentally cut off.
5. The drawing should appear approximately CENTERED inside its bounding box.
6. Do NOT place the bounding box directly on any line, edge, dimension,
   annotation, or other drawing geometry.
7. For narrow views, especially side orthographic views, expand the bounding
   box substantially in the horizontal direction so that the view is not
   cropped at its edges.
8. The bounding box should describe the entire view and its associated
   dimension lines, but should not unnecessarily include neighboring views.
9. Keep separate views in separate bounding boxes. Do not merge multiple
   orthographic views into one bounding box.
10. When determining the boundary, prioritize INCLUDING the entire view over
    making the bounding box as small as possible.
 
 Leave a small amount of empty space between the view geometry and
 the bounding box boundary on ALL sides.
 
 Do not cut off any part of a view.
 Do not merge separate views into one bounding box.
 
 if there are multiple objects with same region types, make a separate bounding box for that region under the same category
 
 If a region type is not present, return an empty list for that category.
 
 the output should look like: 
 {
     "flat_pattern": [],
     "orthographic_view": [
         [something, something, something, something],
         [something, something, something, something]
     ],
     "isometric_view": [],
     "section_view": [],
     "title_block": [
         [something, something, something, something]
     ]
 }
 Do not classify an ordinary orthographic view as a flat_pattern.
 
 Bounding box format: [x0, y0, x1, y1].
 Coordinates must be normalized from 0 to 1000.
 
 return in JSON format only
